## 新的重設工具

`python scripts/reset_lab.py 01` 會先驗證原版 SHA-256、備份現在的列管檔案，再還原該 Lab。所有備份完成後才開始覆寫。工具不刪除自己新增的檔案、筆記、其他 Lab 或外部專案。

測試在獨立暫存專案 fixture 進行，沒有拿學習者的真實練習檔案做破壞性測試。檢查包含：

1. 還原前備份修改，且保留筆記。
2. dry-run 不寫入任何檔案。
3. 原版被修改時，拒絕覆寫。
4. manifest 企圖跳出 Lab 路徑時，拒絕操作。
5. 未知 Lab 編號拒絕操作。
6. 中文標題可正常列出。

實際驗證時發現 Windows Python 繼承 cp932，列中文標題可能失敗；已讓此 CLI 明確輸出 UTF-8，並補中文測試。測試來源在 `tests/test_reset_lab.py`。

## 重現

```powershell
cmake -S . -B build -DPX4LITE_ROOT=D:/px4-lite_learning
cmake --build build --parallel 1
ctest --test-dir build --output-on-failure -V
python scripts/reset_lab.py --list
python scripts/reset_lab.py 04 --dry-run
```

執行中的 Windows EXE 需先停止才能重新連結。沒有外部 PX4-Lite 時可省略 `PX4LITE_ROOT`，但不會建立或測試 Lab 06，因此不能宣稱六組都已驗證。
