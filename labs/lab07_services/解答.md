# Lab 07 解答與講解

這份解答對應 [練習題](練習.md)。[reference/src/main.cpp](reference/src/main.cpp) 保存未修改的完整程式；下列文字解釋修改後應如何判斷。

## 練習 1：解釋 parameter wire float

PX4 使用 bytewise parameter encoding，INT32 的 bits 裝在 float 欄位裡；把它數值轉 int 不會得到 10040。真正 REAL32 的值才可直接當浮點數比較。

## 練習 2：讀懂 TIMESYNC

請求 tc1=0、ts1=本機送出時間；回覆 ts1 鏡射原值、tc1 是對端時間。RTT 來自本機兩次時間差，offset 取中點估計。兩個 monotonic clock 的原點不同，不是 UTC 校時。

## 練習 3：Mission 參數不能整段照抄

Waypoint param2 是 acceptance radius，Land param2 是 precision landing 選項。本次實際 PX4 曾拒絕錯誤值，修正後逐項下載核對成功。上傳成功不表示任務已開始飛。

## 為什麼重做要重啟？

磁碟上的新 EXE 不會改變已經在跑的舊行程。bridge／模型也會保留上次 armed、mode、位置等狀態；重啟新的練習對端，才能把改程式的效果與舊狀態分開。

重設工具只還原已列在基準 manifest 裡的檔案，會先保存你的當前版本；自己的筆記和新增檔案保留。若改過共用 helper，另用 `python scripts/reset_lab.py common` 還原，並重新建立所有受影響的 target。
