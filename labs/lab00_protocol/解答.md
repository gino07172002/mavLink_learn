# Lab 00 解答與講解

這份解答對應 [練習題](練習.md)。[reference/src/main.cpp](reference/src/main.cpp) 保存未修改的完整程式；下列文字解釋修改後應如何判斷。

## 練習 1：逐 byte 輸入

在最後一個必要 byte 到達前不應交給業務邏輯；unsigned frame 的總長度由 header、實際 payload 與 CRC 決定，不要寫死 payload struct 的 sizeof。

## 練習 2：損壞與復原

損壞 frame 應因 CRC 被拒絕；後續有效 frame 仍可被接收。CRC 只能提供完整性檢查，不能認證發送者。

## 練習 3：來源隔離

每條 byte stream 的半包狀態不同。交錯餵進同一個 parser 會污染狀態；單獨持有狀態才有明確邊界。

## 為什麼重做要重啟？

磁碟上的新 EXE 不會改變已經在跑的舊行程。bridge／模型也會保留上次 armed、mode、位置等狀態；重啟新的練習對端，才能把改程式的效果與舊狀態分開。

重設工具只還原已列在基準 manifest 裡的檔案，會先保存你的當前版本；自己的筆記和新增檔案保留。若改過共用 helper，另用 `python scripts/reset_lab.py common` 還原，並重新建立所有受影響的 target。
