# Lab 02 解答與講解

這份解答對應 [練習題](練習.md)。[reference/src/main.cpp](reference/src/main.cpp) 保存未修改的完整程式；下列文字解釋修改後應如何判斷。

## 練習 1：命令容器與命令 ID

message ID 76 表示七參數命令容器；command 400 才表示 Arm／Disarm，param1=1 是 Arm、0 是 Disarm。header 的 sysid/compid 是發送者，payload target 才是接收者。

## 練習 2：故障注入

deny：拒絕、退出碼 3；drop-first：第二次成功；silent-ack：三次後 timeout、結果未知；no-state：ACK 成功但狀態確認失敗、退出碼 4；progress：等待最終結果，不立刻重送；spoof：錯來源／收件者／命令 ACK 被忽略。

## 練習 3：為什麼不能只等 ACK？

no-state 證明 ACK 與後續狀態必須分開觀察；silent-ack 其實已改變模型狀態，但 client 沒收到回覆，因此 timeout 不代表一定沒執行。正式產品需要處理這個不確定性。

## 為什麼重做要重啟？

磁碟上的新 EXE 不會改變已經在跑的舊行程。bridge／模型也會保留上次 armed、mode、位置等狀態；重啟新的練習對端，才能把改程式的效果與舊狀態分開。

重設工具只還原已列在基準 manifest 裡的檔案，會先保存你的當前版本；自己的筆記和新增檔案保留。若改過共用 helper，另用 `python scripts/reset_lab.py common` 還原，並重新建立所有受影響的 target。
